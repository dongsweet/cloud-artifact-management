Agent 接入与 Core 身份

注册 Agent

Agent 在本地生成 Ed25519 身份密钥。请从 Agent 的身份配对页面复制公钥到这里完成配对；Core 不保存 Agent 私钥。注册后，将 Agent 编号配置到对应 Agent，等待签名确认后才显示配对成功；默认每 90 天自动轮换。

Core 服务身份

各 Agent 使用同一份 Core 服务公钥；每台 Agent 的私钥仍独立保存在本机。在 Agent 的“Core 身份配对”中粘贴下方公钥并保存、测试。Core 轮换后，在各 Agent 点击“更换 Core 身份”更新信任。

Agent 身份轮换

Core 下发策略和轮换请求，Agent 主动连接后在本机生成新密钥并确认。离线时请求保留，失败后自动重试；私钥始终留在 Agent。
